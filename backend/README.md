# Backend

This is slashdave's backend.

## Technology

 * [Node.js](https://nodejs.org/en/)
 * [MongoDB](https://www.mongodb.com/)

## Client javascript

See the client directory above this one. All content in ```public/js``` is generated.

## Configuration

Settings are read from ```.env``` (see [dotenv](https://www.npmjs.com/package/dotenv)):

 * ```port```: port to listen on
 * ```dbroute```: MongoDB connection string

## Deployment

The site's ```index.html``` and all javascript are generated by the client
build, so always build the client first:

```
cd client
npm run build
```

## AWS

For Elastic Beanstalk, zip the backend directory. The result is ready to be
deployed on a standard node environment. The ```-FS``` option syncs an
existing archive with the directory, so stale build files are removed:

```
cd backend
zip -FS -r ../backend.zip . -x 'node_modules/*' '*.DS_Store' '*.map'
```

Note that the archive includes ```.env```, which holds the database credentials.
